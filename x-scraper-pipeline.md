- **Provider:** twitterapi.io (`/twitter/tweet/advanced_search`, 20 tweets/page, `since_time:`/`until_time:` unix operators; `since:`/`until:` NOT supported). 15 credits per tweet returned ($0.15/1k); 15-credit minimum per call. Nico recharged 2M credits (~$20) on 2026-09-29 — **hard limit, no more money**. Academic discount: email hello@twitterapi.io from .edu. Replaced Apify.
- **Runtime:** GitHub Actions in `ftm2-rice/Sentiment_analysis_repo` (public). Files in repo ROOT (`scrape.py`, `config.py`, `requirements.txt`, `.github/workflows/scrape.yml`). Cron daily 12:10 UTC, 120-min timeout. Modes: `daily` (default), `test` (≤100 fetched), `bonus` (≤640 fetched), `backfill` (deep one-off).
- **daily mode (v4, Nico's spec):** Phase 1 fresh window (last 48 h, 5 pages/query, never in ledger) → Phase 2 walk backwards one ISO week at a time (fixed Monday boundaries) from current week down to **HISTORY_START = 2024-12-01**, 4 pages/query/week, ledger skips done weeks (containment-aware: a month marked done covers its weeks) → sweep stops at 70% of target → thread expansion (40 threads × 3 pages) fills to **1,000 clean new rows**. Cap 2,500 fetched/run (~$0.375 worst case).
- **Budget guard:** `BUDGET_USD = 18` (config, env override). Script sums `dc_runs.est_cost_usd` at startup; refuses to run past the limit and trims a run's cap so it can't cross it. Estimated cost to exhaust history: $3–5 over ~5–8 runs; then <$1/month.
- **Storage:** Supabase `vratrduscknivoxbrfww`: `dc_tweets` (PK tweet_id), `dc_runs`, `dc_coverage` (window_start, window_end, query_idx, query_type). Needs `sb_secret_…` key. Supabase MCP connector has no access — Nico pastes SQL. Ledger seeded manually for the 2026-09-29 bonus run (May–Aug 2026 = 56 rows). Observed API speed ~8 s/page.
- **Topic gate (query):** CORE_TERMS (data center / centro de datos …) AND Argentina anchors. Stargate/Milei/Caputo removed as anchors. International wires removed from outlets. Outlets added: econojournal, dpl_news, Minergyar, enriquecarrier, Voceria_Ar.
- **Topic gate (code):** `is_on_topic()` — TOPIC_RE + ARGENTINA_RE both required; texts >600 chars need them within 200 chars (outlet accounts exempt); false-Argentina phrases ignored. Noise ~5–10% on real samples.
- **Dedupe:** tweet_id PK + text-only near-duplicate filter per run + coverage ledger.
- **Tags:** `source_type` ∈ news_reply / news_quote / news_thread / verified_opinion / general_public / outlet_post; `outlet_handle`, `matched_query`, `run_mode`. Exclude outlet_post from sentiment. No quotas; balance at analysis time.
- **Bot filter:** X automated label, username pattern, >150 posts/day, <14-day accounts, RTs, short/mention-only replies.
